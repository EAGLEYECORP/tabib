# Tabib.ma V5
Functional core: Next.js + Supabase + Vercel + GitHub.

## Run
npm install
npm run dev

Copy `.env.example` to `.env.local`, create Supabase project, run `supabase/schema.sql`, then configure Vercel.

## Important
Not certified for real health data. Legal/privacy/security review, provider contracts, backup/DR, monitoring and penetration testing are required before production healthcare use.
